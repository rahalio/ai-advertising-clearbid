# Clearbid — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Performance marketer (advertiser)

- As a performance marketer, I want to define a target action and the maximum I will pay for it, so that my budget is exposed to outcomes rather than to traffic volume.
- As a performance marketer, I want the exchange to forecast achievable action volume and cost before I commit budget, so that I am not required to burn a test budget for three months to learn whether a channel works.
- As a performance marketer, I want to see which audience segments and placements drove verified actions, so that I can reallocate rather than guess.
- As a performance marketer, I want invalid traffic removed from my invoice automatically, so that I am not paying first and clawing back later.
- As a performance marketer, I want to compare Clearbid's verified cost per action against my incumbent channel on the same conversion definition, so that I can justify shifting budget internally.

### Publisher monetisation manager

- As a monetisation manager, I want to see predicted revenue per thousand impressions for Clearbid demand against my current demand stack, so that I can decide which inventory to route here.
- As a monetisation manager, I want independent confirmation that a conversion occurred on the advertiser's property, so that my payout does not depend on the advertiser's goodwill.
- As a monetisation manager, I want to block advertiser categories that conflict with my editorial standards, so that participating does not damage my audience relationship.
- As a monetisation manager, I want to raise a dispute when recorded actions and settled amounts diverge, so that shaving has a consequence and a deadline.

### Fraud and quality analyst

- As a fraud analyst, I want to investigate traffic patterns behind rejected actions, so that I can distinguish a compromised placement from a mis-specified conversion tag.
- As a fraud analyst, I want the platform to quarantine a placement automatically when invalid-traffic rates breach a threshold, so that exposure is capped without waiting for a human decision.

### Finance and revenue assurance

- As a finance analyst, I want a period statement that reconciles recorded actions, exclusions, disputes, and invoiced amounts, so that the month closes without manual spreadsheet reconciliation.
- As a finance analyst, I want advertiser credit ratings to govern deferred-payment eligibility, so that we extend terms without taking uncontrolled counterparty risk.

### Platform administrator and compliance officer

- As a compliance officer, I want to evidence the consent basis and purpose limitation for targeting data, so that we can answer a regulator or a publisher's privacy review.
- As a platform administrator, I want conversion records to be append-only with a verifiable history, so that I can demonstrate that neither the exchange nor a counterparty rewrote a settled outcome.
- As a compliance officer, I want a documented resolution path when a counterparty claims a recorded action was invalid, so that exceptions do not become precedent-setting private deals.
